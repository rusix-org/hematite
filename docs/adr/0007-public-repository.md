# ADR 0007: publish the Hematite repository

Status: accepted by Aaron on 2026-10-25.

Aaron explicitly requested a new public `rusix-org/hematite` repository and
publication of the current code. This authorizes repository creation and push,
and public use of this repository name despite the provisional naming status
in ADR 0003. It supersedes earlier local-only publication restrictions.

The preliminary name-collision evidence in ADR 0003 remains applicable; no
additional name clearance is claimed. No license was selected by this request:
ADR 0002 remains proposed, and no license text or SPDX grant is added.
