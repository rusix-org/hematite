# ADR 0003: Keep the name provisional

Status: proposed; public name unresolved, Aaron's approval required.
Date: 2026-10-25

## Recommendation

Keep `hematite` as the local working directory/codename only. Choose another
public name after ADR 0001 settles project direction; contributing upstream
may need no separate kernel brand. Existing software uses make this name a
poor distinct identifier. No rename or public release is authorized here.

Search queries included `hematite Rust kernel operating system github`,

`"hematite" software github python HTTP`. These establish collisions, not an
exhaustive inventory or a legal clearance opinion. Search indexing and record
status may lag reality.

## Remaining gate

No public-name clearance is claimed. No complete USPTO, CIPO, EUIPO, WIPO,
domain, package namespace, or confusingly similar name search was performed.
The [USPTO's clearance guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks)
explains why both registries and common-law uses matter; its
[search guidance](https://www.uspto.gov/trademarks/search/federal-trademark-searching)
also requires considering related goods and similar wording.

For the selected candidate, record dated results in intended jurisdictions,
software/project/package/domain collisions, and Aaron's final decision before
public use, as required by [AGENTS.md](../../AGENTS.md). Appending `OS` or
`kernel` is not assumed to resolve the existing collisions.
